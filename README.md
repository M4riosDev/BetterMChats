## About

BetterMChats replaces Minecraft’s default chat with a clean, animated HUD system inspired by FiveM and GTA roleplay environments.

It provides:
- Custom chat channels  
- Styled messages (icons, labels, colors)  
- HUD overlay instead of vanilla chat  
- Smooth animations  

Designed for roleplay servers and advanced server setups.
